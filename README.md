# Читалка EN → RU

Открываешь английский материал (ссылка, вставленный текст или файл), а при нажатии на слово появляется перевод на русский.

## Что умеет

- **Ссылка на статью.** Страница скачивается, из неё выделяется сама статья.
- **Свой текст.** Можно вставить любой текст.
- **Файл.** PDF, DOCX, TXT и MD: выбрать или перетащить в любое место страницы.
- **История.** Последние 20 статей, текстов и файлов запоминаются в браузере целиком, поэтому открываются мгновенно и без интернета. В списке есть удаление отдельных записей и очистка.
- **Перевод по клику** с вариантами по частям речи и озвучкой слова.
- **Настройки (⚙).** Язык перевода выбирается в списке из 16 языков: русский, украинский, белорусский, казахский, немецкий, французский, испанский, итальянский, португальский, польский, чешский, турецкий, китайский, японский, корейский, арабский. Выбор запоминается в браузере, по умолчанию русский. Исходный язык всегда английский.
- **Перевод в контексте.** Под переводом слова показывается предложение, в котором оно стоит, и его перевод. В переводе подсвечивается слово, соответствующее нажатому, а в основной строке стоит значение, подходящее по смыслу. Обычный словарный перевод остаётся строкой «В словаре».
- Ссылкой можно поделиться: `https://<user>.github.io/<repo>/?url=https://example.com/article`.

## Как устроено

- Статический сайт без сборки: `site/index.html`, `site/style.css`, `site/app.js`.
- Статья скачивается через публичные CORS-прокси (allorigins, corsproxy.io, r.jina.ai) и очищается библиотекой [Readability](https://github.com/mozilla/readability). Текст чистится через [DOMPurify](https://github.com/cure53/DOMPurify), каждое слово оборачивается в `<span>`.
- PDF читает [pdf.js](https://github.com/mozilla/pdf.js), DOCX: [mammoth](https://github.com/mwilliamson/mammoth.js). Обе библиотеки подгружаются только при открытии файла. Из PDF собираются абзацы (`site/pdf-text.js`): убираются номера страниц и колонтитулы, склеиваются переносы слов и абзацы на стыке страниц, заголовки определяются по размеру шрифта. Сканы без текстового слоя не читаются.
- Перевод берётся из Google Translate (неофициальный endpoint), запасной вариант: MyMemory. Переводы слов кэшируются в `localStorage` отдельно для каждого языка. Список языков задан в `LANGS` в начале `site/app.js`, чтобы добавить язык, достаточно дописать туда код и название. В немецком регистр перевода слова не меняется (существительные пишутся с заглавной), в японском распознаются скобки 「」, а у арабского текста направление определяется автоматически.
- Как находится слово в контексте: сайт вырезает предложение вокруг слова (`Intl.Segmenter`, запасной вариант: регулярное выражение; слишком длинные предложения обрезаются до окна около 280 символов), берёт нужное слово в кавычки и отправляет предложение на перевод. Переводчик обычно переносит кавычки в русский текст вокруг перевода именно этого слова, по ним оно и выделяется. Если кавычек получилось не ровно две (или они уже были в тексте), выделение не показывается, а перевод предложения остаётся. Выделение не всегда точное, это подсказка, а не гарантия. Если слово не удалось отделить (например, оно вошло в оборот, как «the legend goes» → «как гласит легенда»), основная строка помечается как словарный перевод, а смысл нужно смотреть в переводе предложения. Слова из заглавных букв (три и больше подряд, как в начале журнальных статей) перед отправкой приводятся к обычному регистру, иначе переводчик их искажает.
- История хранится в `localStorage` (индекс и содержимое под разными ключами). При нехватке места самые старые записи удаляются, документы больше примерно 1,2 млн символов в историю не попадают.
- Все библиотеки лежат в `site/vendor/`, внешних CDN нет.

## Деплой

Workflow `.github/workflows/deploy.yml` публикует папку `site/` на GitHub Pages при каждом пуше в `main`.

Один раз включи Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Локальный запуск

```bash
cd site
python3 -m http.server 8000
# открой http://localhost:8000
```

Открывать `index.html` двойным кликом (`file://`) нельзя: pdf.js загружается как модуль и требует http.
